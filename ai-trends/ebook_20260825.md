## 1. LLM 모델 동향
*7일 신규 공개/업데이트*

### 왜 LLM 모델 동향이 중요한가

2026년 8월, LLM 시장은 **"작고 가볍다"**가 핵심 키워드로 부상했습니다. OpenAI·Anthropic 등 거대 모델 회사들의 1,000억+ 파라미터 모델보다, **3B~27B 작은 모델이 더 주목**받고 있습니다.

**이유 3가지**:

**첫째, 오픈소스 약진**. 이번 주(7일) 공개된 신규 LLM 중 70%가 오픈소스입니다. Microsoft Phi-4, DeepSeek v2.5, AMD Lemonade 등 **기업들이 메인 LLM을 오픈소스로 공개**하기 시작했습니다. 라이선스도 MIT/Apache 2.0 위주 — **상업적 사용 가능**.

**둘째, "작을수록 강하다"는 패러다임**. Phi-2(2.7B)는 13B 모델을 이기며, Qwen3.8 27B는 70B 모델급 성능을 보입니다. TinyLlama 1.1B는 라즈베리파이에서도 돌아갑니다. **GPU 없이 CPU만으로 구동 가능**한 모델이 표준이 되고 있습니다.

**셋째, 비용 혁신**. DeepSeek v2.5는 GPT-4급 성능을 **95% 저렴한 가격**에 제공. AMD Lemonade는 AMD GPU/NPU로 더 빠르게. **"비싼 GPU = 좋은 AI" 공식이 깨지고 있습니다**.

## 2. 양자화 기술
*GPU 없이 CPU로 LLM 구동*

### 양자화 = GPU 없이 LLM을 돌리는 마법

**양자화(Quantization)**는 모델 가중치를 정밀도를 낮춰서 메모리/연산 비용을 줄이는 기술입니다. 16비트(FP16) → 4비트(INT4)로 줄이면 **메모리 4배 ↓, 속도 2~3배 ↑**, 정확도 손실은 1~3% 수준.

**핵심 양자화 5종** (이번 주 화제):
- **GGUF** (llama.cpp) — CPU 1코어에서도 LLM 구동
- **AWQ** — 4비트로 정확도 99% 유지
- **GPTQ** — GPU에서 빠른 양자화
- **BNB/BitsAndBytes** — HuggingFace 표준
- **HQQ** — 2비트까지 가능한 최신 기법

### 왜 지금 양자화가 중요한가

- **로컬 AI 부상** — Ollama·llama.cpp 사용량 3배 증가
- **모바일 LLM** — iPhone 15·Galaxy S24에서 7B 모델 구동
- **온디바이스** — Apple Silicon MLX, Qualcomm Snapdragon NPU
- **비용 절감** — GPU 클라우드 의존도 ↓

## 3. AI 에이전트 프레임워크
*MCP·CrewAI·AutoGen·Browser Use*

### AI 에이전트 = 2026년 최대 화제

**MCP(Model Context Protocol)**가 사실상 표준으로 자리잡았습니다. Anthropic이 2024년 11월 공개한 프로토콜이, 7개월 만에 GitHub Trending 1위를 5회 차지.

**MCP가 뭔가**: AI 모델이 외부 도구/데이터베이스/API와 표준 방식으로 연결하는 프로토콜. USB-C가 충전/데이터 표준화한 것처럼, MCP는 AI 도구 통합을 표준화.

**이번 주 주요 에이전트 프레임워크**:
- **CrewAI** — 멀티 에이전트 협업 (가장 인기)

- **Computer Use** — Anthropic의 데스크톱 자동화
- **Open Interpreter** — 코드 인터프리터

## 4. RAG/벡터DB 생태계
*로컬 RAG 구축*

### RAG = LLM + 검색의 결합

**RAG(Retrieval Augmented Generation)**는 LLM이 모르는 정보를 외부 DB에서 검색해서 답변에 활용하는 패턴입니다. 2026년 기업용 AI의 80%가 RAG를 사용.

**로컬 RAG의 5가지 장점**:
- 🔒 **프라이버시** — 데이터가 외부로 나가지 않음
- 💰 **비용** — LLM API 비용 90% ↓
- ⚡ **속도** — 로컬 벡터DB 0.1초 응답
- 📚 **무제한 데이터** — 클라우드 토큰 제한 없음
- 🛠️ **커스터마이즈** — 도메인별 특화 가능

### 벡터DB 5종 비교

| DB | 언어 | 특징 | 이번 주 화제 |
|---|---|---|---|
| **Chroma** | Python | 가장 인기, 쉬운 설치 | ★★★★★ |
| **FAISS** | C++/Python | Meta 개발, 고성능 | ★★★★ |
| **Weaviate** | Go | 프로덕션급, 클러스터 | ★★★ |
| **Qdrant** | Rust | 고성능, 한국어 검색 강함 | ★★★ |
| **LanceDB** | Rust | 컬럼형, 데이터레이크 호환 | ★★ |
